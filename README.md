# Wazuh-Based SOC Monitoring and Incident Investigation Using Linux

## Overview

A hands-on SOC monitoring and incident investigation project using Wazuh and Linux in an isolated virtual lab environment.

## Key Investigations

- SSH authentication failure detection
- Brute-force activity detection
- File Integrity Monitoring (FIM)
- ClamAV malware detection using the EICAR test file
- Security alert analysis and investigation
- Evidence and timeline analysis
- MITRE ATT&CK mapping

## Technologies

- Wazuh
- Wazuh Manager
- Wazuh Agent
- Wazuh Dashboard
- Kali Linux
- VirtualBox
- OpenSSH
- ClamAV
- MITRE ATT&CK

## Investigation Workflow

Alert → Evidence → Timeline → Analysis → Findings → Actions → Conclusion
